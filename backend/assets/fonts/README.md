# Calendar export font

`DejaVuSans.ttf` is an unmodified DejaVu Sans font, bundled for reproducible
Cyrillic rendering on Linux and macOS. The accompanying license must ship with it.

Source: Matplotlib v3.10.8, `lib/matplotlib/mpl-data/fonts/ttf/`:

- https://raw.githubusercontent.com/matplotlib/matplotlib/v3.10.8/lib/matplotlib/mpl-data/fonts/ttf/DejaVuSans.ttf
- https://raw.githubusercontent.com/matplotlib/matplotlib/v3.10.8/lib/matplotlib/mpl-data/fonts/ttf/LICENSE_DEJAVU
